# COLD MIND — Android MVP

Нативное Android-приложение на Kotlin + Jetpack Compose, полностью на русском языке.

## Возможности
- 12-недельная программа с тремя этапами: фундамент, адаптация, интеграция.
- Семь типов занятий в неделю; упражнения с отметками выполнения и таймером.
- Тренажёр из восьми сценариев с обратной связью и подсчётом правильных ответов.
- Дыхательная практика 4/6 на 3 минуты с таймером и записью завершённых сессий.
- Локальная статистика. Данные сохраняются в Android SharedPreferences.
- Работа без аккаунта и интернета, без разрешений на доступ к личным данным.

## Сборка в Android Studio
1. Установите Android Studio (с поддержкой Android Gradle Plugin 8.7.x), JDK 17 и Android SDK Platform 35.
2. Откройте папку `COLD_MIND` через **File → Open**.
3. Дождитесь Gradle Sync. Android Studio скачает необходимые зависимости (нужен интернет при первой сборке).
4. Запустите приложение на Android 8.0+ (API 26+) через **Run**.
5. Для APK: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
6. APK будет в `app/build/outputs/apk/debug/app-debug.apk`.

## Gradle
Проект содержит `gradle/wrapper/gradle-wrapper.properties`, но **не содержит gradle-wrapper.jar** и shell-скрипты wrapper: в среде создания отсутствовали Gradle, Android SDK и сетевой доступ. Android Studio обычно может использовать установленный Gradle или предложить настроить Gradle Wrapper; при необходимости создайте wrapper командой `gradle wrapper --gradle-version 8.9` с установленным Gradle 8.9. Альтернативно в Android Studio настройте локальный Gradle 8.9.

## Ограничения MVP
- Сборка и запуск не проверены в Android SDK: SDK и Gradle недоступны в среде генерации.
- Программа — учебный инструмент, не заменяет курсы первой помощи, занятия с инструктором или медицинскую помощь.
- Таймер решений показывает секунды, но среднее время ответов пока не сохраняется.
- Сохранение через SharedPreferences подходит для MVP; при дальнейшем расширении стоит перейти на Room/DataStore.
- Нет облачной синхронизации, уведомлений, аудиосопровождения и фонового таймера.
